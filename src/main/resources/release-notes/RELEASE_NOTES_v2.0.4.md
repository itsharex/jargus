# 百目 JArgus v2.0.4

面向版本迭代与性能打磨的一次工程优化版本：打包产物固定为 `jargus.jar`，新增**一键更新**能力，多项高频查询走 SQL 聚合替代 Java 内存循环，结果页 / PDF 报告 / 项目环境分析加了缓存。

## 本次更新

### 一键更新

- 「系统设置」检测到新版本后，新增「一键更新」按钮：自动从 Gitee（GitHub 兜底）下载最新 jar、校验版本与文件完整性、备份当前 jar 为 `.bak`、自动重启应用，全程无需手工替换文件
- 下载进度实时展示，重启完成后页面自动刷新；仅管理员可触发，Windows / IDE 类路径 / 不可写目录下自动隐藏该按钮
- 下载源固定为配置的官方仓库地址，不接受用户输入，规避 SSRF

### 打包产物固定名

- 可执行 jar 固定为 `jargus.jar`（不再附带版本号后缀），下载后直接替换即可，无需改文件名
- README 与官网部署文档同步更新

### 性能优化

- **结果页（扫描结果）**：项目环境分析（POM/依赖扫描）加 LRU 缓存，二次访问从 ~300ms 降到 ~30ms
- **仪表盘**：五级问题总数与近 14 天趋势改为 SQL `SUM` / `DATE() GROUP BY`，不再拉 200 条任务进 Java 循环加总
- **统计接口**：问题分布、技术债分钟数、任务五级计数均改为单条 `GROUP BY` 聚合查询，消除全表实体拉取
- **PDF 报告**：中文字体静态缓存避免每次加载；PDF 文件已存在且新于任务完成时间时直接复用，避免邮件通知等场景重复生成
- **数据迁移**：启动时五级严重度迁移在数据已为新格式时直接短路，不再全量重算任务计数、不再清空全部报告缓存
- **CI 本地扫描**：直接复用本地源码目录，删除「先打 zip 再解压」的冗余 IO
- **批量落库**：AI 批量回写问题包一层 `TransactionTemplate`，避免逐条提交事务
- 生产环境 Thymeleaf 开启模板缓存；应用日志等级从 DEBUG 回调到 INFO，降低磁盘占用
